GENZPHOTO — Image Guide / Panduan Gambar
==================================================

You can replace any image on the website simply by dropping your image files with the exact names listed below into their respective folders:

1. HERO SECTION:
   - File: `images/hero-bg.jpg`
   - Description: Full-screen hero background photo (1920x1080px or higher recommended)

2. ABOUT SECTION:
   - File: `images/about.jpg`
   - Description: Studio or photographer portrait photo (600x800px recommended)

3. SERVICES (PORTFOLIO):
   - `images/services/graduation.jpg`  -> Graduation photoshoot photo
   - `images/services/prewedding.jpg`  -> Pre-wedding photoshoot photo
   - `images/services/product.jpg`     -> Commercial product photoshoot photo
   - `images/services/event.jpg`       -> Event documentation photo

4. CAMERA PRODUCTS (SHOP):
   - `images/cameras/sony-a6400.png`   -> Sony Alpha a6400 (Transparent PNG recommended)
   - `images/cameras/fujifilm-xt30.png`-> Fujifilm X-T30 II (Transparent PNG recommended)
   - `images/cameras/canon-r50.png`    -> Canon EOS R50 (Transparent PNG recommended)
   - `images/cameras/sony-a7iii.png`   -> Sony A7 III (Transparent PNG recommended)
   - `images/cameras/gopro-hero12.png` -> GoPro HERO 12 (Transparent PNG recommended)

5. TEAM MEMBERS:
   - `images/team/member1.jpg` -> Lead Photographer photo (Square/1:1 ratio, e.g. 400x400px)
   - `images/team/member2.jpg` -> Visual Editor photo (Square/1:1 ratio, e.g. 400x400px)
   - `images/team/member3.jpg` -> Studio Manager photo (Square/1:1 ratio, e.g. 400x400px)

*NOTE: If any image file is not yet added, the website will automatically display a clean, elegant fallback vector illustration so it never looks broken!
